# 소아 마취 준비 · 아이폰 홈 화면 웹앱

아이폰 Safari에서 열어 홈 화면에 추가할 수 있는 PWA입니다.

**의료진 확인용 참고 계산기입니다. 실제 처방이나 삽관 지시가 아닙니다.** 앱의 산식은 사용자 제공 준비표를 전산화한 것으로 일반 가이드라인이나 장비 제조사 권장사항과 일부 다를 수 있습니다. 투여 전 마취과 처방과 병원 프로토콜을 대조해야 합니다.

## 주요 기능

- 만 나이(세, 개월), 키, 체중, 수술명 입력 → 실시간 환산
- ETT 후보 3.0 또는 3.5 + 만 나이/4 (0.5mm 반올림), 예상 깊이 tube size × 3 ± 0.5cm
- Blade, Mask 색상, 원내 Cuff 번호, TEE 구간
- Midazolam 0.1–0.2mg/kg, Pentotal Sodium 2–3mg/kg, Esmeron 0.6mg/kg, Sufentanil 0.2–0.3mcg/kg 단순 곱셈
- 최근 5건 기기 내 저장, 복사, 인쇄, Safari 홈 화면 추가, 오프라인 캐시

## 배포

GitHub 저장소 Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

접속 예상 주소: https://asy020.github.io/pediatric-anesthesia/

아이폰 Safari → 공유 → 홈 화면에 추가.

※ 저장 시 환아 이름·등록번호 등 식별정보를 입력하지 마세요.
